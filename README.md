# 🎓 AI Study Buddy

AI Study Buddy is a student-friendly web application built using Python, Flask, and Google Gemini AI. It helps students understand complex topics in simple language, making learning easier, faster, and more interactive.

## 🚀 Features

- 🤖 AI-powered learning assistant
- 📚 Explains topics in simple student-friendly language
- ❓ Answers academic questions instantly
- ⚡ Fast and interactive responses
- 🎨 Simple and clean user interface
- 🌐 Web-based application accessible through a browser

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Google Gemini AI API

## 💡 How It Works

1. The student enters a question or topic.
2. The application sends the query to Gemini AI.
3. Gemini generates a simple explanation.
4. The response is displayed on the webpage.
5. Students can learn concepts quickly and effectively.

## 🎯 Use Cases

- Homework assistance
- Quick concept revision
- Learning difficult topics
- Exam preparation
- Understanding academic concepts in simple language

## 🔧 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Study-Buddy.git
```

2. Open the project folder

```bash
cd AI-Study-Buddy
```

3. Install required packages

```bash
pip install flask google-generativeai
```

4. Run the application

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000
```
